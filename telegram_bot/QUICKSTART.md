# 🚀 Быстрый запуск Telegram бота

## Шаг 1: Получение токена

1. Найдите [@BotFather](https://t.me/botfather) в Telegram
2. Отправьте `/newbot`
3. Следуйте инструкциям
4. Скопируйте токен

## Шаг 2: Настройка окружения

```bash
# Перейдите в папку проекта
cd telegram_bot

# Активируйте виртуальное окружение
source venv/bin/activate

# Установите токен
export BOT_TOKEN="ваш_токен_от_botfather"
```

## Шаг 3: Запуск

### Автоматический запуск:
```bash
./run_bot.sh
```

### Ручной запуск:
```bash
# Базовая версия
python main.py

# Расширенная версия (рекомендуется)
python advanced_bot.py
```

## Шаг 4: Тестирование

```bash
# Запустить демонстрацию компонентов
python demo.py
```

## 🎯 Готово!

Найдите вашего бота в Telegram и отправьте `/start`

---

**💡 Совет:** Сохраните токен в файле `.env` для постоянного использования:

```bash
echo "BOT_TOKEN=ваш_токен" > .env
```
