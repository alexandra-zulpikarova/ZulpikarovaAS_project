# 🛒 Система чекбоксов для Telegram бота

## 📝 Описание

Система чекбоксов позволяет создавать интерактивные меню для выбора различных позиций с возможностью указания количества. Идеально подходит для:

- 🛍 **Интернет-магазинов** - выбор товаров и оформление заказов
- 📋 **Опросов** - множественный выбор вариантов ответов  
- ✅ **Todo-списков** - отметка выполненных задач
- 🍕 **Ресторанов** - создание заказа блюд
- 🎫 **Бронирований** - выбор услуг и опций

## ✨ Возможности

### 🎯 Основной функционал:
- ☐/✅ **Чекбоксы** для выбора позиций
- 🔢 **Ввод количества** с кнопками ➕/➖
- 🏷 **Категории товаров** для группировки
- 🛒 **Корзина** с подсчетом общей стоимости
- 📱 **Адаптивный интерфейс** с inline-кнопками

### 🔧 Технические особенности:
- 👥 **Многопользовательский режим** - у каждого своя корзина
- 💾 **Управление состоянием** корзины
- 🔄 **Динамическое обновление** интерфейса
- ⚡ **Быстрые операции** добавления/удаления
- 🛡 **Безопасная обработка** callback'ов

## 🚀 Быстрый старт

### 1. Запуск магазина
```
/shop              # Команда в чате
🛍 Магазин         # Кнопка в главном меню
```

### 2. Навигация по категориям
- 🍕 **Пицца** (3 вида)
- 🍔 **Бургеры** (2 вида)  
- 🥤 **Напитки** (2 вида)
- 🍰 **Десерты** (2 вида)

### 3. Выбор товаров
- ☐ Нажмите на товар → ✅ Добавлен в корзину
- ✅ Нажмите снова → ☐ Удален из корзины
- ➕/➖ Изменение количества

### 4. Оформление заказа
- 🛒 **Моя корзина** → просмотр выбранного
- ✅ **Оформить заказ** → получение номера заказа

## 🎯 Пример использования

### Сценарий: Заказ пиццы

1. **Открытие магазина**
   ```
   Пользователь: /shop
   Бот: 🛍 Добро пожаловать в наш магазин!
   ```

2. **Выбор категории**
   ```
   Пользователь: [🍕 Пицца]
   Бот: Показывает список пицц с чекбоксами
   ```

3. **Добавление товаров**
   ```
   ☐ 🍕 Пицца Маргарита - 450₽
   ☐ 🍕 Пицца Пепперони - 520₽
   
   После выбора:
   ✅ 🍕 Пицца Маргарита - 450₽
   [➖] [Количество: 1] [➕]
   ```

4. **Изменение количества**
   ```
   Пользователь: [➕]
   ✅ 🍕 Пицца Маргарита (2) - 450₽
   [➖] [Количество: 2] [➕]
   ```

5. **Просмотр корзины**

6. **Оформление заказа**
   ```
   ✅ Заказ #ORD20250730195123456 оформлен!
   
   Детали заказа:
   • 🍕 Пицца Маргарита
     2 шт. × 450₽ = 900₽
   
   Итого: 900₽
   Статус: Принят в обработку
   ```

## 🛠 Техническая документация

### Структура данных корзины
```python
{
    "items": {
        "pizza_margherita": 2,    # item_id: quantity
        "drink_cola": 1
    },
    "created_at": datetime,
    "updated_at": datetime
}
```

### Основные функции CheckboxManager

#### `toggle_item(user_id, item_id)`
Переключает выбор товара (добавляет/удаляет из корзины)
```python
was_added = manager.toggle_item(12345, "pizza_margherita")
# True - товар добавлен, False - удален
```

#### `set_item_quantity(user_id, item_id, quantity)`
Устанавливает количество товара
```python
manager.set_item_quantity(12345, "pizza_margherita", 3)
```

#### `calculate_total(user_id)`
Рассчитывает общую стоимость заказа
```python
totals = manager.calculate_total(12345)
# {"total_price": 1350, "total_items": 3, "items_count": 1}
```

### Callback данные

| Префикс | Описание | Пример |
|---------|----------|---------|
| `category_` | Выбор категории | `category_pizza` |
| `toggle_` | Переключение товара | `toggle_pizza_margherita` |
| `qty_increase_` | Увеличить количество | `qty_increase_pizza_margherita` |
| `qty_decrease_` | Уменьшить количество | `qty_decrease_pizza_margherita` |
| `remove_` | Удалить из корзины | `remove_pizza_margherita` |
| `show_cart` | Показать корзину | `show_cart` |
| `confirm_order` | Оформить заказ | `confirm_order` |

## 📊 Статистика и аналитика

### Отслеживаемые метрики:
- 👥 **Количество пользователей** в системе
- 🛒 **Содержимое корзин** каждого пользователя
- 💰 **Общая стоимость** заказов

### Получение статистики:
```python
# Всего пользователей
total_users = len(checkbox_manager.user_carts)

# Общая сумма всех корзин
total_value = sum(
    checkbox_manager.calculate_total(user_id)["total_price"]
    for user_id in checkbox_manager.user_carts.keys()
)
```

## 🐛 Troubleshooting

### Частые проблемы:

**1. Не работают чекбоксы**
```
Решение: Проверьте регистрацию обработчиков
setup_checkbox_handlers(dp)
```

**2. Не сохраняется состояние корзины**
```
Решение: Убедитесь, что используете один экземпляр CheckboxManager
```

**3. Ошибки callback'ов**
```
Решение: Проверьте префиксы в handle_checkbox_callbacks()
```

**4. Не отображаются товары**
```
Решение: Проверьте структуру AVAILABLE_ITEMS и CATEGORIES
```
